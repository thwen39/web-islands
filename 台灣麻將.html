📖 台灣十六張麻將規則與台數表

基本規則：共 144 張牌（萬筒條各36、風牌16、三元牌12、花牌8）。莊家起手 17 張、閒家 16 張，自動補花。逆時針輪流摸打，牌牆剩餘 16 張（鐵八墩）流局。

操作方式：輪到您出牌時，點一下手牌選取（牌會浮起），再點一次該牌（或雙擊）即可打出。當可吃、碰、槓、胡或自摸時，下方會彈出金色發光操作列。

優先順序：胡牌 ＞ 碰 / 槓 ＞ 吃牌（僅限吃上家打出的牌）。

常見台數一覽：
  • • 莊家：1台 / 連N拉N：2N台
  • • 門清：1台 / 自摸：1台
  • • 門清一摸三：3台
  • • 正花（對應門風）：各1台 / 花槓：2台
  • • 中/發/白刻子：各1台
  • • 圈風刻 / 門風刻：各1台
  • • 獨聽 / 邊張 / 中洞：1台
  • • 槓上開花 / 海底撈月：1台
  • • 平胡（無字花兩面聽非自摸）：2台
  • • 全求人：2台 / 半求人：1台
  • • 碰碰胡：4台 / 混一色：4台
  • • 清一色：8台 / 小三元：4台 / 大三元：8台
